# SatQuery AI

SatQuery AI is a multimodal remote-sensing analysis interface for exploring satellite imagery and SAR data through natural-language queries.

This repository reflects the project as a GitHub contribution-focused implementation, with the original ISRO/SIH26167 branding removed from the product UI and public metadata.

## Local development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

## Build

```bash
npm run build
```

## Notes

- Frontend: Vite + React + TypeScript
- Styling: Tailwind CSS
- Purpose: visual analysis, dataset exploration, and satellite insight workflows
